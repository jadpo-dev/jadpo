# The Jadpo name

Jadpo's code is licensed under the [Apache License 2.0](LICENSE), which gives
no rights to the name (section 6). This page says how the name "Jadpo" may be
used.

You may, without asking:

- refer to Jadpo by name, in writing, talks, teaching and reviews;
- say that software is written in, built with or compatible with Jadpo, or
  that a package or tool is for Jadpo;
- redistribute unmodified Jadpo releases under the name Jadpo.

A modified version of Jadpo must use a different name, and must not suggest
that it is Jadpo or that the Jadpo project endorses it. It may say that it is
based on Jadpo.

Ask first, by opening an issue at
[richardwillars/jadpo](https://github.com/richardwillars/jadpo), before using
the name in the name of a product, service, company or domain, or selling
anything under it.
