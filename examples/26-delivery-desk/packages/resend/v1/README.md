# @jadpo/resend

Sends your app's email through Resend's API. A Jadpo provider package, called `Resend.v1` in your app.

It lives in its own repository so each release is this repository at a tag, which is how
jadpo.dev's package registry publishes every package. Once the registry opens:

```sh
jadpo package add @jadpo/resend
```

It moved here from `packages/` in [jadpo-dev/jadpo](https://github.com/jadpo-dev/jadpo), with its history.
