# `translation.sources_invalid`

A translations folder's sources record cannot be read.

## Why Jadpo refuses it

`sources.jadpo_record` records which default wording each translation was
made from and who accepted it. Jadpo writes it, and it judges from it whether
a translation has gone stale or hasn't been accepted, so a file it can't
read would hide both.

## What it looks like

A line in the record has been written by hand, in words Jadpo doesn't read.

```jadpo check project=e-tr-sources-invalid file=app.jadpo hidden
application {}

locales {
    default: Locale.en_gb
    supported: [Locale.en_gb, Locale.de_de]
}
```

```jadpo check project=e-tr-sources-invalid file=domains/greeting/translations/hello.jadpo hidden
/// Says hello.
type Hello = Message {
    name: Text
}
```

```jadpo check project=e-tr-sources-invalid file=domains/greeting/translations/en_gb.jadpo hidden
translations {
    hello: "Hello, {name}."
}
```

```jadpo check project=e-tr-sources-invalid file=domains/greeting/translations/de_de.jadpo hidden
translations {
    hello: "Hallo, {name}."
}
```

`domains/greeting/translations/sources.jadpo_record`:

```jadpo check project=e-tr-sources-invalid file=domains/greeting/translations/sources.jadpo_record expect=translation.sources_invalid
// Generated by Jadpo from this folder's translations; update it with `jadpo translations update`, never by hand.
record translations 1

translation de_de.hello was made from Hello, {name}.
```

```text output
error: `domains/greeting/translations/sources.jadpo_record` can't be read: this line is not a translation entry
 --> domains/greeting/translations/sources.jadpo_record:4:1
  |
4 | translation de_de.hello was made from Hello, {name}.
  | ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^ this line is not a translation entry
  reason: This file records which wording each translation was made from and who accepted it. Jadpo writes it, and a stale or unaccepted translation is judged from it, so a file it can't read hides both.
  next: Run `jadpo translations update`, which writes it again (agent)
  rule: translation.sources_invalid
  help: https://jadpo.dev/docs/errors/translation.sources_invalid

check failed: 1 error, 4 files
```

`(agent)` at the end of the `next:` line means your coding agent can make
the fix itself.

## How to fix it

**If the record is damaged or was hand-edited**, have Jadpo write it again:

```sh
jadpo translations update
```

```jadpo check project=e-tr-sources-invalid-fix file=app.jadpo hidden
application {}

locales {
    default: Locale.en_gb
    supported: [Locale.en_gb, Locale.de_de]
}
```

```jadpo check project=e-tr-sources-invalid-fix file=domains/greeting/translations/hello.jadpo hidden
/// Says hello.
type Hello = Message {
    name: Text
}
```

```jadpo check project=e-tr-sources-invalid-fix file=domains/greeting/translations/en_gb.jadpo hidden
translations {
    hello: "Hello, {name}."
}
```

```jadpo check project=e-tr-sources-invalid-fix file=domains/greeting/translations/de_de.jadpo hidden
translations {
    hello: "Hallo, {name}."
}
```

```jadpo check project=e-tr-sources-invalid-fix file=domains/greeting/translations/sources.jadpo_record hidden
// Generated by Jadpo from this folder's translations; update it with `jadpo translations update`, never by hand.
record translations 1

translation de_de.hello from 2e5b444cecc5 wording acb00cba6dc3
```

The file again says which wording each translation was made from.
