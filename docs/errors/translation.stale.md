# `translation.stale`

A translation was made from default wording that has changed.

## Why Jadpo refuses it

A translation is made from the default locale's wording, and
`jadpo translations update` records which wording that was. When the default
wording changes, the translation may no longer say the same thing, so Jadpo
treats it as an error until someone looks again. A locale still being
translated, listed in `in_progress:`, is listed by
`jadpo translations missing` instead.

## What it looks like

The English wording has changed to "Good day" since the German was made
from "Hello", and the record says so.

```jadpo check project=e-tr-stale file=app.jadpo hidden
application {}

locales {
    default: Locale.en_gb
    supported: [Locale.en_gb, Locale.de_de]
}
```

```jadpo check project=e-tr-stale file=domains/greeting/translations/hello.jadpo hidden
/// Says hello.
type Hello = Message {
    name: Text
}
```

```jadpo check project=e-tr-stale file=domains/greeting/translations/en_gb.jadpo hidden
translations {
    hello: "Good day, {name}."
}
```

```jadpo check project=e-tr-stale file=domains/greeting/translations/sources.jadpo_record hidden
// Generated by Jadpo from this folder's translations; update it with `jadpo translations update`, never by hand.
record translations 1

translation de_de.hello from 2e5b444cecc5 wording acb00cba6dc3
```

`domains/greeting/translations/de_de.jadpo`:

```jadpo check project=e-tr-stale file=domains/greeting/translations/de_de.jadpo expect=translation.stale
translations {
    hello: "Hallo, {name}."
}
```

```text output
error: `hello` in `de_de` was translated from `en_gb` wording that has since changed
 --> domains/greeting/translations/de_de.jadpo:2:5
  |
2 |     hello: "Hallo, {name}."
  |     ^^^^^ made from the old `en_gb` wording
  reason: `jadpo translations update` recorded the `en_gb` wording this message's translation was made from, and the `en_gb` wording has changed since, so the translation may no longer say the same thing.
  next: Reword `hello` in `domains/greeting/translations/de_de.jadpo` to match the new `en_gb` wording, then run `jadpo translations update` (agent)
  rule: translation.stale
  help: https://jadpo.dev/docs/errors/translation.stale

check failed: 1 error, 4 files
```

`(agent)` at the end of the `next:` line means your coding agent can make
the fix itself.

## How to fix it

**If the translation needs to change**, reword it, then run
`jadpo translations update`. In `domains/greeting/translations/de_de.jadpo`:

```jadpo fragment
    hello: "Guten Tag, {name}."
```

```jadpo check project=e-tr-stale-fix file=domains/greeting/translations/de_de.jadpo hidden
translations {
    hello: "Guten Tag, {name}."
}
```

```jadpo check project=e-tr-stale-fix file=app.jadpo hidden
application {}

locales {
    default: Locale.en_gb
    supported: [Locale.en_gb, Locale.de_de]
}
```

```jadpo check project=e-tr-stale-fix file=domains/greeting/translations/hello.jadpo hidden
/// Says hello.
type Hello = Message {
    name: Text
}
```

```jadpo check project=e-tr-stale-fix file=domains/greeting/translations/en_gb.jadpo hidden
translations {
    hello: "Good day, {name}."
}
```

```jadpo check project=e-tr-stale-fix file=domains/greeting/translations/sources.jadpo_record hidden
// Generated by Jadpo from this folder's translations; update it with `jadpo translations update`, never by hand.
record translations 1

translation de_de.hello from 1948ea97b022 wording 72973ec801bc
```

The German matches the new English wording, and the record now says it
was made from it.

**If the translation still says the same thing**, only record that:

```sh
jadpo translations update
```

```jadpo check project=e-tr-stale-keep file=app.jadpo hidden
application {}

locales {
    default: Locale.en_gb
    supported: [Locale.en_gb, Locale.de_de]
}
```

```jadpo check project=e-tr-stale-keep file=domains/greeting/translations/hello.jadpo hidden
/// Says hello.
type Hello = Message {
    name: Text
}
```

```jadpo check project=e-tr-stale-keep file=domains/greeting/translations/en_gb.jadpo hidden
translations {
    hello: "Good day, {name}."
}
```

```jadpo check project=e-tr-stale-keep file=domains/greeting/translations/sources.jadpo_record hidden
// Generated by Jadpo from this folder's translations; update it with `jadpo translations update`, never by hand.
record translations 1

translation de_de.hello from 1948ea97b022 wording acb00cba6dc3
```

```jadpo check project=e-tr-stale-keep file=domains/greeting/translations/de_de.jadpo hidden
translations {
    hello: "Hallo, {name}."
}
```

The translation is kept, and the record now names the current English
wording.

**If it will be translated later**, list the locale in `in_progress:` in
`app.jadpo`:

```jadpo fragment
    in_progress: [Locale.de_de]
```

```jadpo check project=e-tr-stale-progress file=app.jadpo hidden
application {}

locales {
    default: Locale.en_gb
    supported: [Locale.en_gb, Locale.de_de]
    in_progress: [Locale.de_de]
}
```

```jadpo check project=e-tr-stale-progress file=domains/greeting/translations/hello.jadpo hidden
/// Says hello.
type Hello = Message {
    name: Text
}
```

```jadpo check project=e-tr-stale-progress file=domains/greeting/translations/en_gb.jadpo hidden
translations {
    hello: "Good day, {name}."
}
```

```jadpo check project=e-tr-stale-progress file=domains/greeting/translations/sources.jadpo_record hidden
// Generated by Jadpo from this folder's translations; update it with `jadpo translations update`, never by hand.
record translations 1

translation de_de.hello from 2e5b444cecc5 wording acb00cba6dc3
```

```jadpo check project=e-tr-stale-progress file=domains/greeting/translations/de_de.jadpo hidden
translations {
    hello: "Hallo, {name}."
}
```

`jadpo translations missing` lists the stale wording until the locale
leaves `in_progress:`.
