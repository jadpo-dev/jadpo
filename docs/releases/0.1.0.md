# Jadpo 0.1.0

Released 30 October 2026.

The first release of Jadpo: the compiler, the `jadpo` command and the VS Code extension. See
[Learn Jadpo](https://jadpo.dev/learn) to build your first app.

## New

- **`jadpo new`** starts a project.
- **`jadpo build`** builds an app, from any folder.
- **The Jadpo version an app needs.** `jadpo:` in `application { }` names the version of Jadpo the
  app is written for, and the `jadpo` command runs the matching release.
- **Tenants.** In an app that serves many customer organisations, each one a tenant, a value that
  must be unique only has to be unique within its tenant.
- **Tests sign in through magic links**, the sign-in emails Jadpo sends.
- **Help lines link to jadpo.dev**: every error's `help:` line is its page on the site.
- **Bug reports from coding agents.** An agent can draft a bug report about Jadpo for you to read
  and send.
- **The VS Code extension**, published with each release.
