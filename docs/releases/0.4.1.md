# Jadpo 0.4.1

Released 7 November 2026.

This release fixes downloading Jadpo 0.4 for a project that needs it. It changes nothing in the
language or the compiler.

## Fixed

- **`jadpo` from an earlier release can download Jadpo 0.4.** When a project's `jadpo:` names a
  newer version than the `jadpo` you run, `jadpo` downloads that version and checks the download
  was built from its release. Jadpo 0.4.0's download couldn't be checked that way, so `jadpo`
  0.3.0 refused it with `toolchain.version_newer`. Jadpo 0.4.1's can. Installing 0.4.0 directly
  always worked.
